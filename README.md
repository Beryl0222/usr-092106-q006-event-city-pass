# 赛事城市联动通行证

本仓库保存该服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件信封、聚合类型和事件类型（赛历版本、通行证与转赠、权益库存/预约/核销、限流冻结、改道、补偿、商户结算、清算、匿名证据与归因）。
- `docs/event-catalog.md`：事件目录、payload 字段约定、资金来源枚举。
- `docs/cancellation-drill.md`：**关键演练——比赛取消**。处置时间线、已使用/未使用补偿矩阵、在途观众可执行改道、断网重传一次扫码只核销一次、转赠责任链、限流最小作用域冻结。
- `docs/attribution-and-evidence.md`：匿名化核销证据、哈希链封档、赛事新增消费 vs 普通客流归因，每个汇总数可重算复核。
- `data/cancellation-drill.json`：58 条事件的端到端演练流（由脚本生成，哈希与汇总自洽）。
- `data/sample.json`：单条中文样例记录。
- `src/`：事件信封校验、去重助手（`dedupeEnvelope`）、哈希/规范化工具。
- `tests/`：样例契约 + 取消演练的 12 项领域不变量（共 13 个测试）。

## 核心原则

1. **事件只追加**：标识、发生时间和版本不原地改写；赛历改期/取消产生新版本，业务更正产生后继事件。
2. **不回滚通行证**：取消按**单条预约**处置——已使用不退现金、未使用按替代或退款分流，一笔补偿只记一个资金来源。
3. **商户只结算真实核销**：结算笔笔对得上匿名证据；晚于商户退出生效时间的争议扫码挂起裁定，不默认赔付。
4. **在途观众先收到可执行选择**：改道选项带实时余量、操作入口和有效期，选择即生成替代预约。
5. **限流只冻结相交时段**：时段与区域双相交才冻结，解除后同聚合新版本恢复，不波及无关权益。
6. **幂等**：跨系统消息按信封 `event_id` / 扫码 `idempotency_key` 去重，断网重传只核销一次。
7. **最小化读取**：证据侧不出现姓名、证件号、手机号、订单原文；归属判定用盐化 HMAC/双盐哈希。
