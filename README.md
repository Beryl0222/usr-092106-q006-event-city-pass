# 赛事城市联动通行证

本仓库保存该服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：事件信封基础字段、聚合类型、事件类型、资金来源与金额约束。
- `docs/domain.md`：聚合、事件目录与十条领域不变量（去重、幂等核销、时段冻结、分账补偿、真实核销清算、匿名归因等）。
- `docs/cancellation-drill.md`：**关键演练——比赛取消**的时间线、补偿矩阵、商户清算与归因复算。
- `data/sample.json`：最小中文样例记录。
- `data/cancellation-drill.jsonl`：取消比赛完整事件流（45 条消息，含重传/重放、替代、结算、归因）。
- `src/validator.js`：事件信封校验、信封去重与扫码幂等。
- `src/reconcile.js`：补偿台账、商户清算、时段冻结、赛历版本链与归因数字的纯函数复算。
- `tests/`：验证样例与演练流的全部汇总数可复核。

## 领域边界

事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正只产生后继记录。比赛取消不回滚整张通行证：已使用、未使用与在途权益按替代方案和资金来源分别补偿，商户只按真实核销结算，限制只冻结受影响时段。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段；消费归因只使用匿名化证据。
